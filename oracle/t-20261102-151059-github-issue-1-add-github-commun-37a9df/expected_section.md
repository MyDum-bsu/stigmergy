# Пример раздела, который проходит oracle

Не копировать дословно: это образец структуры и обязательных токенов.
Тест `tests/test_agents_md_github_section.py` проверяет `AGENTS.md` в корне
репозитория; файл лежит рядом как справка для worker'а.

```markdown
## GitHub

Задачи и PR живут в GitHub (`MyDum-bsu/stigmergy`), учёт работы — на доске;
issue лишь зеркало, доска — источник истины.

- Вход: `gh issue view <N>` — прочитать постановку, `gh issue list` — очередь.
  Изменения в постановке ведёт доска, issue не переписываем.
- Выход: `gh pr create --base dev` из feature-ветки; прямых пушей в `dev` и
  `main` нет.
- Связь с доской: `stg board` — статус задачи; PR привязывается командой
  `board pr <id> --pr <N>`.
- Ревью и комментарии — через `gh pr review` / `gh pr comment`; ответ на issue
  допустим только как зеркальное уведомление.
- Закрытие задачи — событие доски (`stg worker done`), не закрытие issue.
```
