# PRD — GitHub-коммуникация в AGENTS.md

ID: t-20261102-151059-github-issue-1-add-github-commun-37a9df
Источник: MyDum-bsu/stigmergy#1 (issue — зеркало, доска — источник истины).

## Goal

В `AGENTS.md` появляется отдельный раздел `## GitHub`, который фиксирует, как
агенты в этом репозитории работают с GitHub: вход (`gh issue`), выход (`gh pr`),
связь issue ↔ задача доски (`stg board`, `board pr <id> --pr <N>`) и правило
«issue — зеркало, доска — источник истины». Раздел проверяется тестом, а не
чтением глазами.

## Non-goals

- Не меняем остальные разделы `AGENTS.md` (Работа, Приёмка, Ветки) и не
  переформатируем файл.
- Не трогаем `src/stigmergy/**`, `pyproject.toml`, `.factory/integration/*.toml`.
- Не настраиваем GitHub Actions, шаблоны issue/PR, labels, CODEOWNERS.
- Не описываем `gh` API целиком: только правила работы агента в этом репозитории.
- Не переносим раздел в другие копии `AGENTS.md` за пределами этого worktree.

## Use cases

1. Worker получил задачу из issue #N: по разделу видно, что задачу ведёт доска,
   issue — зеркало, и что после PR нужно вызвать `board pr <id> --pr <N>`.
2. Новый агент (pi/opencode/codex/claude) читает `AGENTS.md` и понимает, что
   `gh issue` / `gh pr` — штатный путь, а `stg board` — учёт работы.
3. Ревьюер проверяет, что агент не закрывает задачу через GitHub и не правит
   issue вместо доски.

## UX

Раздел `## GitHub` — обычный markdown-раздел второго уровня в конце
`AGENTS.md`, в стиле остальных разделов: короткое вступление одной строкой,
дальше список `- ` из 4–7 пунктов с конкретными командами в backticks.
Заголовок и токены технические, поэтому читаются одинаково на любом языке.

## Edge cases

- **Заглушка вместо содержания.** Раздел из одного заголовка или с `TBD`/`TODO`
  не проходит: тест считает это провалом.
- **Раздел ниже третьего уровня** (`### GitHub`) — не считается: тест ищет
  `## GitHub`.
- **Две секции `## GitHub`** — провал (дубль правил хуже их отсутствия).
- **Разрушающая правка.** Если при добавлении раздела пропадает `## Работа`,
  `## Приёмка` или `## Ветки`, тест падает.
- **Правка только прозой.** Если в разделе нет `gh issue`, `gh pr`, `stg board`
  и `MyDum-bsu/stigmergy`, тест падает: правила без команд не проверяемы.
- Текст issue #1 недоступен (в запросе только заголовок), поэтому требования
  заданы списком обязательных токенов и минимумом пунктов, а не дословной
  формулировкой.

## Risks

- **Документ регламентирует поведение агентов.** Слишком жёсткий текст может
  запретить штатные действия; снимается тем, что раздел не вводит новых правил,
  а фиксирует уже действующие (доска — источник истины, `main` только через
  `stg promote`).
- **Хрупкий тест.** Привязка к русским корням (`зеркал`, `доск`) ломается при
  смене формулировки; поэтому проверяются корни, а не словоформы, и это
  записано в спеке.
- **Расхождение копий.** Внешняя копия `AGENTS.md` (главный чекаут) останется
  без раздела; это осознанно вне скоупа.
- Риск низкий: правка документа + один новый тест, обратима одним revert.
